 # 🧠 Gemini Chain-of-Thought Agent  A small, hands-on AI agent built in Python that *thinks out loud* before it answers.  Instead of replying in one shot, the agent works in three steps: 
 1. **PLAN**: it breaks your question down and decides what to do.
 2. **TOOL**: if it needs outside help, it calls a tool and waits for the result
 3. **OUTPUT**: once it has enough information, it gives you the final answer.  You can watch every step in the terminal, which makes it a nice way to see how agents actually reason and use tools under the hood.  ## ✨ What it can do  - 🌦️ **Check the weather** for any city (via [wttr.in](https://wttr.in), no API key needed) - 💻 **Run commands on your computer** (asks for your confirmation first) - 🔁 Keep the full conversation history, so it remembers context between steps - 📦 Return structured JSON every turn, validated with Pydantic

 1. What is the weather in Delhi? The user wants the weather of Delhi. I have a get_weather tool for this. >> get_weather(delhi) >>> the weather in delhi is Sunny +31°C The current weather in Delhi is sunny at 31 degrees Celsius. ```  ## 🚀 Getting started

Every reply is forced into a fixed JSON shape (`step`, `content`, `tool`, `input`) using a Pydantic model. A simple loop reads the `step` field:  - `PLAN` → print the thought and ask the model to continue - `TOOL` → run the matching Python function and feed the result back as an `OBSERVE` message - `OUTPUT` → print the final answer and wait for your next question  ## 🛠️ Adding your own tool  1. Write a Python function that takes a string and returns a string. 2. Add it to the `available_tools` dictionary. 3. Describe it in the `AVAILABLE TOOLS` section of the system prompt.  That's it. Read the command before you approve it, and don't remove that check.  ## 📌 Ideas for the future  - Web search tool - File read/write tools - Streaming responses - A simple web UI  ## 📄 License  MIT
